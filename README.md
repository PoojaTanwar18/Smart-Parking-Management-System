# Smart Parking Management System

The **Smart Parking Management System** is a database-driven project designed to efficiently manage parking lots, parking slots, vehicles, and parking records. The system helps track parking availability, vehicle entry and exit details, parking duration, and parking-related information in an organized manner.

The project is developed using **MySQL/SQL** and demonstrates practical implementation of database concepts such as **table creation, primary keys, foreign keys, relationships, constraints, joins, aggregate functions, subqueries, views, and SQL queries**.

### Key Features

* Manage multiple parking lots and parking slots.
* Maintain vehicle information and registration details.
* Record vehicle entry and exit times.
* Track occupied and available parking slots.
* Maintain complete parking history.
* Analyze parking utilization and vehicle activity.
* Generate useful reports using SQL queries.
* Retrieve business insights using joins, filtering, grouping, and aggregate functions.

### Database Tables

The system includes major entities such as:

* **Parking_Lots** – Stores parking lot information.
* **Parking_Slots** – Maintains individual parking slot details and availability.
* **Vehicles** – Stores vehicle and owner-related information.
* **Parking_Records** – Records vehicle entry, exit, parking duration, and related transactions.

### Objective

The main objective of this project is to demonstrate how a relational database can be used to build an organized parking management solution. It provides hands-on experience in **database design, SQL query development, data management, and analytical reporting**.

This project is suitable for demonstrating practical **SQL/MySQL and Database Management System (DBMS)** skills in a portfolio, resume, or technical interview.
